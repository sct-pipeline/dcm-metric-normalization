  build_surgery_mapping.py
      Builds the surgery-scan mapping table (who had surgery, when relative to
      which MRI session). Synthesises check_surg_dates, merge_all_subjects,
      add_months_diff, and add_timepoint_columns into a single documented pipeline.

  generate_figure_PAM50_multiple_subjects.py
      Plots group-level spinal cord metric profiles across vertebral levels in
      PAM50 space, with optional stratification by MCL group or myelopathy and
      optional spine-generic normative reference bands.

  plot_boxplots_violins_by_level.py
      Produces boxplots, violin plots, and strip plots of per-level morphometric
      metrics grouped by vertebral level and timepoint, with automatic outlier
      annotation.

  plot_csa_delta.py
      Computes and plots cross-sectional area (CSA) change from baseline and
      from the pre-surgery scan for each subject, using per-level data at the
      stenosis levels.

  plot_groupwise_prepost_by_max_stenosis.py
      Creates group-averaged pre/post surgery PAM50 per-slice profiles stratified
      by maximum stenosis level (e.g. C4/C5, C5/C6), with optional spine-generic
      healthy-controls reference.

  plot_individual_trajectories_pam50.py
      Generates one figure per subject showing their longitudinal PAM50 per-slice
      metric trajectories, with stenosis levels highlighted and time-aware
      therapeutic group labels (operative vs. conservative).

  plot_metrics_at_mcl_perslice.py
      Computes and plots morphometric metrics in a ±N-slice window centred on the
      MCL disc junction. Supports both standard (baseline-aligned) and operative
      (surgery-aligned, months from surgery) modes in native or PAM50 space.

  plot_mjoa_cord_area_violin.py
      Creates a violin plot showing the univariate association between mJOA total
      score and spinal cord cross-sectional area at a chosen vertebral level,
      with Spearman correlation statistics.

  plot_mjoa_longitudinal.py
      Plots longitudinal mJOA trajectories across all timepoints and, for
      operative subjects, trajectories aligned to the estimated surgery date.

  plot_trajectory_zurich_longitudinal.py
      Generates five types of longitudinal trajectory visualisations (per-level,
      per-slice PAM50, per-slice native, level profiles, and group-split by
      therapeutic decision), with time-aware operative/conservative stratification.

1. build_surgery_mapping.py
--------------------------------------------------------------------------------
Git status : Committed 2026-04-20 (commit 413bd20)
Created    : 2026-04-20

PURPOSE
  Builds the baseline_surgery_dates_merged_clean.csv table used by operative
  analysis scripts. It consolidates four previously separate scripts into a
  single, commented pipeline:
    Step 1 — extract surgery dates from clinical_scores.xlsx
    Step 2 — load M0 scan dates from participants.tsv
    Step 3 — merge the two tables (left join on subject)
    Step 4 — compute months from M0 scan to surgery (relativedelta)
    Step 5 — assign nominal before/after surgery timepoints from months_diff
    Step 6 — verify which timepoints have actual per-slice MRI data
    Step 7 — save the output CSV (refuses to overwrite existing files)

  NOTE: The existing baseline_surgery_dates_merged_clean.csv uses per-session
  scan dates (not just M0) from a later REDCap export. This script uses the M0
  date from participants.tsv, so months_diff values will differ for ~40 subjects,
  but the before/after timepoint assignments agree for 42/43 operative subjects.

FUNCTIONS
  get_parser()
    Define CLI arguments; returns ArgumentParser.

  extract_surgery_dates(clinical_scores_path)
    Read clinical_scores.xlsx, collect all surg_date_* columns (excluding
    surg_date_before_* which are scan dates, not surgery dates), and keep only
    subjects whose surgery date is consistent across all filled columns.
    Returns DataFrame(subject:int, surgery_date:datetime).

  load_baseline_scan_dates(participants_path)
    Read participants.tsv, extract numeric subject ID and date_of_scan (M0).
    Returns DataFrame(subject:int, date_of_scan:datetime).

  merge_scan_and_surgery(baseline_df, surgery_df)
    Left-join on subject; adds subject_bids (sub-XXX format).
    Returns merged DataFrame.

  compute_months_diff(merged_df)
    For each row with both dates, compute relativedelta(surgery_date, date_of_scan)
    expressed as years*12 + months + days/30, rounded to 2 dp.
    Adds column months_diff_scan_to_surgery.

  assign_nominal_timepoints(merged_df)
    From months_diff, find the last TIMEPOINTS entry strictly before surgery
    (before_surg) and the first at or after surgery (after_surg).
    Subjects with months_diff <= 0 or > 60 get None/None.

  verify_data_existence(df, perslice_dir, structure='cord')
    Build a set of subjects with data at each timepoint by reading
    T2w_ax_{structure}_metrics_perslice_{tp}_data.csv.
    For each subject, walk backwards to find before_surg_found and forwards to
    find after_surg_found. Both may differ from the nominal values when a
    session's data file is missing.

  finalise_and_save(df, output_path)
    Drop numeric subject column, rename subject_bids to subject, format dates
    as YYYY-MM-DD strings, sort, and save. Raises FileExistsError if output
    already exists.

  main()
    Runs Steps 1–7 in order, printing progress at each step.

CLI ARGUMENTS
  --clinical-scores  PATH   clinical_scores.xlsx (required)
  --participants     PATH   participants.tsv (required)
  --perslice-dir     PATH   directory with per-slice metric CSVs (required)
  --output           PATH   output CSV path — will NOT overwrite (required)
  --structure        STR    structure name in filenames (default: cord)

INPUT  : clinical_scores.xlsx, participants.tsv, per-slice metric CSVs
OUTPUT : surgery mapping CSV (subject, date_of_scan, surgery_date,
         months_diff_scan_to_surgery, before_surg, after_surg,
         before_surg_found, after_surg_found)

7. plot_metrics_at_mcl_perslice.py
--------------------------------------------------------------------------------
Git status : Committed 2026-04-20 (commit 4837292)
Created    : 2026-04-20

PURPOSE
  Compute and plot morphometric metrics (CSA, AP diameter, compression ratio)
  in a ±N-slice window centred on the MCL disc junction. Two modes:

  Standard mode  — x-axis is months from M0 baseline; delta relative to M0.
  Operative mode — x-axis is months from surgery; delta relative to last
                   pre-surgery scan (before_surg_found). Requires the surgery
                   mapping CSV produced by build_surgery_mapping.py.

  Supports both native and PAM50 spaces. Space label is included in all plot
  titles.

FUNCTIONS
  get_parser()
    CLI argument parser.

  extract_subject_id(filename)
    Regex-extract sub-XXX.

  parse_mcl(mcl_str)
    Parse 'C4/C5' → (4, 5); returns None on failure.

  load_participants(participants_file)
    Load participant_id and maximum_stenosis; parse MCL into upper_level and
    lower_level integers; drop subjects with unparseable MCL.
    Returns DataFrame(subject, upper_level, lower_level, maximum_stenosis).

  load_perslice_data(data_dir, structure, timepoints, space='native')
    Load per-slice CSVs for all timepoints (native or PAM50 naming);
    filter to C2–C7; compute compression_ratio = diameter_AP / diameter_RL.
    Returns combined DataFrame.

  find_mcl_junction_slices(df_subj_tp, upper_level, lower_level, n_slices)
    In I→S orientation, higher slice = more superior. The upper vertebra
    (e.g. C4) occupies the higher slice numbers; the lower vertebra (e.g. C5)
    occupies lower numbers. Takes the N lowest slices from the upper level and
    the N highest slices from the lower level to form a window centred on the
    disc junction.
    Returns list of slice indices or None.

  extract_metrics_at_mcl(all_data, participants_df, n_slices, metrics)
    For each (subject, timepoint), call find_mcl_junction_slices and average
    metrics across the window. Returns long-format DataFrame with one row per
    (subject, timepoint).

  plot_metric_trajectories(df_mcl, metric, output_dir, space)
    Absolute metric over time (individual faint lines + group mean ± SD).
    Space label shown in title. Saves PNG.

  plot_delta_from_baseline(df_mcl, metric, output_dir, space)
    Change from M0 baseline (individual + group). Space label in title.
    Saves PNG.

  plot_multi_metric_panel(df_mcl, metrics, output_dir, space)
    Grid of all metrics × (absolute | delta). Space label in suptitle.
    Saves PNG.

  plot_by_mcl_group(df_mcl, metric, output_dir, n_slices, space)
    Separate mean ± SD line per MCL group; rare groups (< 3 subjects) merged
    into 'Other'. Space label in title. Saves PNG.

  load_surgery_mapping(mapping_file)
    Load baseline_surgery_dates_merged_clean.csv; keep only rows with both
    before_surg_found and after_surg_found. Returns DataFrame.

  extract_metrics_operative(all_data, participants_df, surgery_mapping,
                             n_slices, metrics)
    For each operative subject:
      1. Extract MCL window at before_surg_found → reference values.
      2. For every timepoint, compute months_from_surgery =
         TIMEPOINT_MONTHS[tp] − months_diff_scan_to_surgery.
      3. Compute delta = value − reference.
    Returns DataFrame with absolute values, delta_* columns,
    months_from_surgery, and phase tag (pre/post_surgery).

  _operative_group_stats(df_plot, y_col)
    Group by timepoint code (not by continuous months_from_surgery, which
    would produce single-subject groups with NaN std). Place each group at its
    mean months_from_surgery on the x-axis.
    Returns DataFrame indexed by mean months_from_surgery.

  _add_surgery_bands(ax, x_min, x_max)
    Draw vertical dashed line at x=0 (surgery) and shade pre/post regions.

  plot_operative_trajectories(df_op, metric, output_dir, space)
    Absolute metric vs months from surgery; surgery line at x=0. Saves PNG.

  plot_operative_delta(df_op, metric, output_dir, space)
    Delta from pre-surgery scan vs months from surgery; pre-surgery point is
    always at delta=0 by construction. Space label in title. Saves PNG.

  plot_operative_panel(df_op, metrics, output_dir, space)
    Summary panel for operative analysis (absolute | delta, all metrics).
    Space label in suptitle. Saves PNG.

  main()
    Parse args; run standard figures or operative figures depending on
    --operative-only flag.

CLI ARGUMENTS
  --data-dir                  PATH   per-slice CSV directory (required)
  --participants              PATH   participants.tsv (required)
  --output-dir                PATH   output directory (required)
  --space                     STR    native | PAM50 (default: native)
  --structure                 STR    cord | canal | aSCOR (default: cord)
  --timepoints                [TPS]  timepoints (default: M0 M6 M12)
  --n-slices                  INT    slices per side of junction (default: 3)
  --metrics                   [MET]  metrics (default: area, AP diam, comp ratio)
  --operative-only            FLAG   use surgery-relative timeline
  --baseline-surgery-mapping  PATH   surgery mapping CSV (required if --operative-only)

INPUT  : per-slice metric CSVs, participants.tsv, optional surgery mapping CSV
OUTPUT : metrics_at_mcl.csv (or metrics_at_mcl_operative.csv),
         PNG figures (trajectories, delta, by_mcl_group, panel,
                      operative_trajectories, operative_delta, operative_panel)

PURPOSE
  Five visualisation options for longitudinal spinal cord morphometrics in the
  DCM-Zurich cohort. Options can be run individually or all at once. Supports
  time-aware stratification by therapeutic group (operative vs. conservative):

    Option 1 — Per-level trajectories over time (colours = vertebral levels)
    Option 2 — Per-slice PAM50 trajectories across slices (colours = timepoints)
    Option 3 — Per-slice native trajectories across slices (colours = timepoints)
    Option 4 — Vertebral level profiles per timepoint (x = level, colours = tp)
    Option 5 — Group-split per-level trajectories: conservative (baseline-aligned)
                and operative (post-op aligned, x-axis = scans since surgery)
